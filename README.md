Quiz bíblico pro

Una plataforma web interactiva y competitiva diseñada para poner a prueba conocimientos bíblicos a través de una experiencia de usuario moderna, fluida y llena de adrenalina. El proyecto utiliza tecnologías web puras (HTML5, CSS3 y JavaScript) con un enfoque estético de tipo glassmorphism.
Descripción del proyecto

Este juego ha sido creado para ofrecer una dinámica de competencia por equipos que escala en dificultad. Cuenta con una interfaz visualmente atractiva que incluye fondos animados, efectos de sonido y una lógica de juego robusta que castiga la indecisión y premia el conocimiento rápido.
Características principales

    Tres niveles de dificultad: Las preguntas progresan de fácil a difícil, ajustando automáticamente los puntos otorgados y el tiempo disponible en el cronómetro.

    Modos de juego:

        Estándar: Basado en turnos y rachas de hasta tres respuestas consecutivas.

        Modo turbo: Transiciones automáticas y rápidas para un flujo de juego constante.

        Supervivencia: Un formato de eliminación directa donde un solo error significa la salida del equipo.

    Mecánica táctica de salto: Los equipos pueden elegir subir de nivel para obtener más puntos, pero deben decidirlo en los primeros segundos del turno antes de que la opción se bloquee.

    Interfaz de videojuego:

        Fondo con partículas geométricas en movimiento.

        Temporizador con efecto de latido visual en momentos críticos.

        Efectos de sonido para aciertos, errores y ambiente.

        Animaciones de escritura (typewriter) para las preguntas.

Requisitos e instalación

El proyecto es totalmente portátil y no requiere dependencias externas ni servidores complejos.

    Descarga: Clona el repositorio o descarga el archivo comprimido.

    Ejecución local: Abre el archivo index.html en cualquier navegador web moderno (Chrome, Firefox, Edge, Safari).

    ** GitHub pages:** También puede ser desplegado directamente desde la configuración de este repositorio para ser jugado de forma remota.

Tecnologías utilizadas

    HTML5: Estructura semántica y contenedores de audio.

    CSS3: Diseño responsivo, variables para temas dinámicos, animaciones de fotogramas (keyframes) y efectos de desenfoque de fondo.

    JavaScript (Vanilla): Motor lógico del juego, gestión de estados, temporizadores de precisión y sistema de seguridad para la integridad de los créditos.
